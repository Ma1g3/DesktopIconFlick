# Spec Delta

## MODIFIED Requirements

### Requirement: 固定准星与相对转向

训练 MUST 将准星固定在视口中心，用鼠标相对位移旋转虚拟视角，不受 Windows 指针速度或加速度影响。局外设置 MUST 默认提供「局内 DPI」和水平 FOV，并将硬件 DPI 和 `cm/360` 收起在可选的高级校准中。对于相同的相对计数，转角 MUST 随局内 DPI 成比例变化。调整 MUST 只影响训练视角，沿用鼠标硬件档位和 Windows 指针设置。

#### Scenario: 直接调整局内 DPI
- **WHEN** 玩家将局内 DPI 从 800 提高到 1600，并在两局输入同样的水平计数
- **THEN** 训练的水平转角加倍，准星仍在视口中心，游戏外的鼠标行为照常

#### Scenario: 相对位移映射为转角
- **WHEN** 玩家展开高级设置，以硬件 DPI 800 和 `cm/360` 40 应用校准
- **THEN** 局内 DPI 换算为 800，累计约 3150 个水平计数产生约 90° 转角

#### Scenario: 改变水平视野
- **WHEN** 玩家仅调低水平 FOV，其他输入设置不变
- **THEN** 正前方的靶子在屏幕上变大，相同鼠标计数对应的转角不变

#### Scenario: 输入无效设置
- **WHEN** 玩家输入超出界面标注范围、非数值或非有限的设置值并提交
- **THEN** 应用提示有效范围，并保留上一组有效设置

#### Scenario: 读取旧配置
- **WHEN** 玩家启动新版并加载只包含硬件 DPI、`cm/360` 和原有偏好的配置
- **THEN** 主界面显示等效局内 DPI，同样的鼠标输入得到原来的转角，保留 FOV、个人最佳及外观和声音偏好

#### Scenario: 保存局内 DPI
- **WHEN** 玩家填写有效的局内 DPI 后开始训练，随后退出并重新启动应用
- **THEN** 应用恢复上次使用的局内 DPI，高级设置仍默认收起
