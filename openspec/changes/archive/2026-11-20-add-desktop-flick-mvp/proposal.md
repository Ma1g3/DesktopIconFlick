# Proposal

## Why

让用户自己的桌面图标成为练习目标。在真实桌面画面上，用相对鼠标输入和固定准星快速切靶，减少两次命中之间找靶和长距离甩动的时间。

## What Changes

- 在 Windows 主屏工作区叠加无边框半透明训练层：壁纸和任务栏不随视角转动，只有游戏中的靶子按相机视角投影。桌面仍可见，但对局点击不会穿透到桌面。
- 直接绘制从 Windows Shell 只读获取的桌面图标副本，保留素材自身的透明区域。可切换普通小球，两种外观共用靶位和球形命中区域。
- 命中图标靶时，让桌面原位自然露出壁纸。动态壁纸继续播放。暂停或结算时原位图标重新可见，继续本局时恢复已命中的显示效果。
- 提供固定中央准星、相对鼠标输入、可调的鼠标 DPI、`cm/360` 和水平 FOV。30 秒三靶模式在紧凑的区域内命中即补靶，结束显示结果和本地个人最佳。
- 失焦或按 `Esc` 时暂停并释放鼠标，须由用户主动恢复对局。首版不做跨屏场地、在线排行、FPS 游戏预设、武器模型或可旋转的壁纸。

## Capabilities

### New Capabilities

- `desktop-training-layer`: 桌面画面合成、图标素材读取，以及训练期间的输入归属与安全退出。
- `flick-training`: 相对鼠标控制、固定准星判定、三靶补位、计时和本地成绩。

### Modified Capabilities

无。

## Impact

- 新增 Windows 10/11 x64 桌面应用原型，涉及 Shell 图标读取、前台鼠标输入、透明渲染和本地配置。
- 不需要修改 Explorer 或文件关联，不使用桌面截图，不上传图标、文件名或训练成绩。
