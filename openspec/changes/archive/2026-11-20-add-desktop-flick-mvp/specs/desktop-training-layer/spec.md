# Spec Delta

## Purpose

让玩家在自己的 Windows 桌面上进入训练，同时将游戏图标、画面和对局输入与系统桌面隔离，确保开始、暂停和结束训练都不改变用户的桌面布局或文件。

## ADDED Requirements

### Requirement: 主屏桌面叠层

训练 MUST 在主显示器工作区显示为无边框半透明叠层，保留可见的真实桌面和任务栏；视角变化 SHALL 只作用于游戏场景。

#### Scenario: 在桌面进入训练并横向转动视角
- **WHEN** 玩家显示桌面后开始训练，并向右移动鼠标
- **THEN** 图标靶相对准星移动，而真实壁纸、桌面图标和任务栏保持原位
- **AND** 训练画面不覆盖任务栏或第二块显示器

### Requirement: 只读使用桌面图标

图标模式 MUST 直接绘制 Windows 当前用户桌面项目的图像副本并保留其透明区域。对局 MUST NOT 给图标靶加上圆形底板、圆环边框或圆形蒙版。训练 MUST NOT 移动、隐藏或打开真实桌面图标，不截取桌面画面，不上传图标或文件信息。

#### Scenario: 桌面图标本身就是靶子
- **WHEN** 桌面上存在可用图标且玩家开始图标训练
- **THEN** 靶位显示熟悉的桌面图标图像，图像的透明区域透出下方画面，直接瞄准图标即可命中

#### Scenario: 首局图标仍在读取
- **WHEN** 玩家已选择使用桌面图标，Shell 素材尚未读取完成
- **THEN** 开始按钮等待图标读取完成，界面提示正在读取
- **AND** 玩家可以切换到普通小球并立即开始

#### Scenario: 无可用图标
- **WHEN** 桌面没有可读取的图标素材
- **THEN** 应用提示已使用普通小球，玩家仍可开始训练

### Requirement: 命中后遮盖原位图标

在能识别桌面图标原位的图标局中，训练 MUST 在命中时用游戏叠层遮盖该靶来源的图标及文字。遮盖 MUST 固定在桌面坐标，且只在本局活动时显示。训练 MUST 保持 Explorer 的图标和文件状态。

#### Scenario: 命中一个有原位的图标靶
- **WHEN** 玩家命中一个可定位的图标靶
- **THEN** 它的原位图标和文字随补靶一起从对局画面消失，其他尚未命中的原位图标仍可见
- **AND** 假如两枚原位图标使用相同图案，只有来源与命中靶一致的一枚被遮盖

#### Scenario: Shell 提供同名项目
- **WHEN** Shell 返回多个同名项目，且 Explorer 桌面视图里只有其中一个对应可定位的原位图标
- **THEN** 使用桌面视图中的实际项目生成靶子，命中后遮盖该项目原位
- **AND** 其余同名 Shell 项目不作为该图标的备用靶素材

#### Scenario: 打空或重复命中
- **WHEN** 玩家打空，或命中来源已经遮盖的图标靶
- **THEN** 已遮盖的区域保持不变

#### Scenario: 暂停、结算或重开
- **WHEN** 玩家暂停、切出窗口、结束对局或退出应用
- **THEN** 训练叠层撤回遮盖，原位图标重新可见
- **AND** 恢复同一局时继续遮盖已命中的图标，新一局从全部图标可见开始

#### Scenario: 命中动态壁纸上的图标
- **WHEN** 玩家命中可定位的桌面图标，且训练能取得该位置的实时背景
- **THEN** 原位露出连续播放的桌面背景，边缘与周围桌面衔接

#### Scenario: 背景无法可靠呈现
- **WHEN** 训练无法可靠显示原位图标下的桌面背景
- **THEN** 对局继续正常计分与补靶，原位保持可见

#### Scenario: 原位无法定位或被其他窗口挡住
- **WHEN** 图标原位无法安全确定、原位完全被其他窗口挡住，或玩家使用普通小球
- **THEN** 对局继续正常计分与补靶，本次命中不覆盖桌面区域

#### Scenario: 原位上方有透明窗口或局部遮挡
- **WHEN** 命中图标的原位上方有全透明窗口或有其他窗口挡住一部分原位
- **THEN** 桌面上仍可见的图标部分被遮盖，其他窗口的可见内容保持可见

### Requirement: 对局输入隔离与释放

应用 MUST 仅在显式开始或恢复且窗口位于前台时隐藏并约束系统光标、处理对局输入。暂停、失焦、结算或退出时 MUST 释放约束并恢复光标，不自动重新接管输入。

#### Scenario: 左键点击没有靶子的区域
- **WHEN** 玩家在对局中点击可透视但未绘制靶子的工作区
- **THEN** 游戏记录一次未命中，底层桌面不收到本次点击

#### Scenario: 离开训练再返回
- **WHEN** 玩家按 `Esc`，或使用 `Alt+Tab` 切至其他窗口
- **THEN** 对局暂停，光标可正常用于系统操作，应用不处理后台瞄准或击发
- **AND** 窗口重新获得焦点时仍保持暂停，直到玩家主动恢复

#### Scenario: 对局时显示配置变化
- **WHEN** 训练中发生使工作区坐标失效的分辨率、缩放或主屏变化
- **THEN** 应用停止当前对局、释放光标，并提示重新开始

#### Scenario: 对局退出或异常终止
- **WHEN** 应用在对局中正常退出或进程被终止
- **THEN** 系统光标可正常使用，且无需恢复桌面图标布局或可见性
