# Spec Delta

## MODIFIED Requirements

### Requirement: 对局输入隔离与释放

应用 MUST 只在前台接管光标和处理对局输入。单机训练 MUST 由玩家显式开始或恢复。局域网竞赛 MUST 由该设备上的玩家主动准备，并仅在约定的开局时点与有效准备状态同时满足时接管。暂停、失焦、结算、竞赛中断或退出时 MUST 释放约束并恢复光标，回焦时不得自动重新接管输入。

#### Scenario: 左键点击没有靶子的区域
- **WHEN** 玩家在对局中点击可透视但未绘制靶子的工作区
- **THEN** 游戏记录一次未命中，底层桌面不收到本次点击

#### Scenario: 离开训练再返回
- **WHEN** 玩家在单机训练中按 `Esc`，或使用 `Alt+Tab` 切至其他窗口
- **THEN** 对局暂停，光标可正常用于系统操作，应用不处理后台瞄准或击发
- **AND** 窗口重新获得焦点时仍保持暂停，直到玩家主动恢复

#### Scenario: 对局时显示配置变化
- **WHEN** 训练中发生使工作区坐标失效的分辨率、缩放或主屏变化
- **THEN** 应用停止当前对局、释放光标，并提示重新开始，竞赛场景按本轮未完赛处理

#### Scenario: 对局退出或异常终止
- **WHEN** 应用在对局中正常退出或进程被终止
- **THEN** 系统光标可正常使用，且无需恢复桌面图标布局或可见性

#### Scenario: 房间准备与前台开赛
- **WHEN** 玩家加入竞赛房间、点击准备并看到倒计时
- **THEN** 应用在约定开局且窗体位于前台时才接管光标
- **AND** 有效准备取消、切出窗口或错过开局后，迟到的通知不允许接管光标

#### Scenario: 竞赛中断释放
- **WHEN** 玩家在竞赛中放弃、失焦、失去鼠标控制，或应用检测到连接中断
- **THEN** 应用结束该玩家的本轮操作，释放光标并撤回桌面遮盖和反馈
- **AND** 后台输入和随后回焦都不恢复本轮操作
