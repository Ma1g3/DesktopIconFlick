# Design

## Context

`TrainingWindow.ApplyRoundInput` 在判定命中后替换靶子，并更新约 80 毫秒的准星提示。原位遮盖有两条路径。`DesktopHitSurface` 绘制静态背景并裁掉挡在桌面前面的窗口，`LiveWallpaperReveal` 为实时壁纸注册对应区域。`TrainingProfile` 通过五行文本存储瞄准设置、图标模式和最佳命中数。

## Goals / Non-Goals

**Goals**

- 让一次命中同时驱动准星、短音效和可用的桌面原位反馈。
- 让玩家在现有 30 秒训练中快速扫一眼 HUD，并在结算立刻看出自己有没有刷新纪录。
- 复用现有渲染时钟、遮挡规则、本地配置和输入释放路径。

## Decisions

1. 以成功命中作为唯一触发点。在替换靶子之前取得其图标来源，随后完成替换和视觉更新。每次命中尝试异步播放约 50 毫秒的本地提示音，重复命中可以重新触发。使用初始化时生成的短 PCM 音样，交给 Windows `PlaySound` 异步播放。音样在播放期间保持有效，停播后释放资源，设备失败时保留视觉反馈。系统通知音的音色取决于用户主题，独立音样可保持反馈一致。 [Windows PlaySound 文档](https://learn.microsoft.com/en-us/previous-versions/dd743680(v=vs.85))
2. 让原位提示以通过验证的桌面矩形为锚点。首次遮盖成功时为该图标登记一个约 220 毫秒的淡出提示。静态路径复用壁纸遮盖的裁剪范围，实时路径根据当前背景区域是否成功注册决定是否显示，并复用遮挡裁剪。`DesktopHitSurface` 使用现有渲染时钟推进提示，活动提示期间才请求重绘。图标矩形内的细角线能在复杂背景上指出位置，也能避免给随视角移动的图标靶加底板或边框。
3. 在暂停、失焦、结算、显示变更和退出的共用清理路径中清掉提示并停播音效。原位提示的计时和原有遮盖集合独立。恢复对局时仍按集合恢复遮盖。
4. 命中音效作为可立即保存的局外开关，使用现有原子写入路径，在五行设置之后追加选项。读取五行或六行格式。音效字段缺失时默认启用，字段损坏时默认启用并保留前五行有效数据。
5. 用固定宽度的数字槽显示剩余秒数、命中和射击数，按信息优先级排版，空间紧时合并为窄版。沿用现有的墨绿面板与浅绿强调色。结算让命中数独占一行成为视觉焦点，后接射击数、命中率、个人最佳和主按钮。保存前比较已有最佳和本局命中，已有正数纪录被超越时显示「新纪录 · 多命中 N 个」。

## Risks / Trade-offs

- **按 DPI 映射的原位偏差** → 使用遮盖已有的物理桌面到 WPF 坐标转换。用非 100% 缩放核对提示与图标位置。
- **实时壁纸的辅助窗口参与遮挡枚举** → 核对应用自身的合成窗口和真正挡住原位的窗口，视觉提示使用与实际可见揭露区域一致的裁剪。
- **快速命中造成重绘堆积或音效排队** → 每处只跟踪有效提示，快速音效复用同一短音样。缓存绘图资源，归档前对照实机快速甩动。
- **旧设置的意外覆盖** → 复用设置文件原子的替换行为，并对五行文件、静音重启和个人最佳做回归。

## Migration Plan

更新后直接读取旧设置。首次保存时追加音效偏好。若需要回退到只能读取五行的构建，备份设置文件后可从副本移除第六行，再用副本替换原设置。
