# Spec Delta

## ADDED Requirements

### Requirement: 原位图标消失提示
命中首次在桌面原位露出壁纸时，训练 MUST 在该原位的可见区域内显示一个短暂淡出的边缘提示。提示 MUST 固定在桌面坐标，并遵循原位遮盖的可见范围。

#### Scenario: 静态或实时背景上的命中
- **WHEN** 图标靶的首次命中使原位图标和文字消失并露出静态或实时背景
- **THEN** 该原位出现短暂的边缘提示，随即淡出，实时背景继续播放
- **AND** 转动视角时提示仍留在桌面原位

#### Scenario: 连续命中不同图标
- **WHEN** 上一处的提示尚未淡出，玩家又命中一枚能露出原位壁纸的图标靶
- **THEN** 两处各自显示和淡出

#### Scenario: 本次命中没有露出新区域
- **WHEN** 玩家打空，或命中小球、原位已经遮盖的图标、原位无法验证的图标、背景无法可靠呈现的图标或原位完全被遮挡的图标
- **THEN** 本次操作不产生原位提示，实际命中仍正常计分和补靶

#### Scenario: 原位部分被应用窗口挡住
- **WHEN** 命中图标靶时，该图标原位部分被其他窗口挡住
- **THEN** 边缘提示只显示在已露出且未被挡住的部分，不覆盖其他窗口的可见内容

#### Scenario: 反馈期间离开对局
- **WHEN** 玩家暂停、切出、退出，或对局结算或因显示配置变化停止
- **THEN** 原位边缘提示立即撤回
- **AND** 继续或重开时不重播此前的提示
