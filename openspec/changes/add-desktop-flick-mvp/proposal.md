# Proposal

## Why

桌面图标台球让用户自己的图标成为游戏道具，但用桌面光标瞄准和 FPS 固定准星甩枪是两种不同的手感。首版要验证：不离开熟悉的 Windows 桌面画面，也能获得相对鼠标输入、固定准星和连续切靶的体验。

## What Changes

- 在 Windows 主屏工作区叠加无边框半透明训练层：壁纸和任务栏不随视角转动，只有游戏中的靶子按相机视角投影。桌面仍可见，但对局点击不会穿透到桌面。
- 用从 Windows Shell 只读获取的图标副本作为圆靶外观；可切换普通小球，两种外观共用同一套靶位和命中规则。不会隐藏、移动或打开真实图标。
- 提供固定中央准星、相对鼠标输入、可调的鼠标 DPI、`cm/360` 和水平 FOV。提供 30 秒三靶模式，命中即补靶，结束显示结果和本地个人最佳。
- 失焦或按 `Esc` 时暂停并释放鼠标，须由用户主动恢复对局。首版不做跨屏场地、在线排行、FPS 游戏预设、武器模型或可旋转的壁纸。

## Capabilities

### New Capabilities

- `desktop-training-layer`: 桌面画面合成、图标素材读取，以及训练期间的输入归属与安全退出。
- `flick-training`: 相对鼠标控制、固定准星判定、三靶补位、计时和本地成绩。

### Modified Capabilities

无。

## Impact

- 新增 Windows 10/11 x64 桌面应用原型，涉及 Shell 图标读取、前台鼠标输入、透明渲染和本地配置。
- 不需要修改 Explorer 或文件关联，不使用桌面截图，不上传图标、文件名或训练成绩。
