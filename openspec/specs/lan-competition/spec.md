# lan-competition Specification

## Purpose

让同一局域网中的玩家各自在自己的 Windows 桌面同时完成一轮甩枪挑战，以共同的开局条件和计分规则比较成绩，并在各自屏幕上查看同一份结算。

## Requirements

### Requirement: 创建与加入局域网房间

应用 MUST 提供单独的「局域网竞赛」入口，允许一名玩家创建房间并展示可分享的局域网 IPv4 地址和端口。其他玩家 MUST 能在同一子网输入该地址、端口与昵称加入。房间 MUST 容纳 2 至 8 名参赛者，人数包含房主。

#### Scenario: 两台电脑加入同一房间
- **WHEN** 房主建房，朋友在同一子网用房主显示的地址和端口加入
- **THEN** 两端均显示同一份玩家名单、房主标识和各人的准备状态

#### Scenario: 区分重名玩家
- **WHEN** 两名玩家使用相同昵称
- **THEN** 房间名单和计分板都能明确区分这两名玩家

#### Scenario: 加入或建房失败
- **WHEN** 地址无效、连接超时、房间已满、版本不兼容、房间当前不可加入，或本地监听失败
- **THEN** 应用显示对应原因或排查提示，并允许返回或重试

#### Scenario: 单机使用
- **WHEN** 玩家启动应用后只使用单机训练
- **THEN** 应用不建立局域网房间，不为竞赛监听或发起连接

### Requirement: 准备与同步开赛

房主 MUST 在房间至少有两人且所有玩家均主动准备时才能开始 3 秒倒计时。触发倒计时时 MUST 锁定参赛名单，并为本轮公布同一个开局时点和截止时点。每位玩家 MUST 仅在开局时点到达后才能计分，截止时点为开局后 30 秒。

#### Scenario: 准备状态变化
- **WHEN** 房内只有一人，或有玩家未准备、取消准备或在等待期间失焦
- **THEN** 房主不能发起倒计时，名单显示当前准备状态

#### Scenario: 房主发起同一轮比赛
- **WHEN** 所有人准备后房主点击开始，且各端保持前台并可正常通信
- **THEN** 所有参赛者看到同一轮倒计时，从同一计划时点进入对局，并从同一计划时点停止计分
- **AND** 倒计时前及期间光标仍可正常操作，在两个连接正常且界面响应的同网段客户端上实测开局偏差不超过 250 毫秒

#### Scenario: 迟到或准备失效
- **WHEN** 玩家错过允许的开局窗口、在倒计时中取消准备或失焦，或到点时无法接管输入
- **THEN** 该玩家本轮记为未完赛并显示相应原因，其余符合开局条件的玩家照常比赛
- **AND** 该玩家随后回焦或收到迟到的通知时不开始该轮，也不接管光标

#### Scenario: 中途尝试加入
- **WHEN** 新玩家在倒计时、对局中或结算等待期间尝试加入
- **THEN** 应用提示本轮进行中，参赛名单保持锁定

### Requirement: 共用靶位规则与独立操作

同一轮 MUST 为每位玩家提供相同的初始三枚靶位和球形命中体，并在命中同一靶位序列时生成相同的补靶序列。玩家的射击 MUST 只影响自己的靶和成绩。玩家 MUST 能使用本地局内 DPI、水平 FOV、靶外观与音效。

#### Scenario: 不同屏幕和外观使用相同靶位
- **WHEN** 两名玩家使用不同宽高比、FOV 或靶外观开赛，并按相同顺序命中相同的靶
- **THEN** 两人的开局与补靶角位置一致，各自视口照常投影，命中体和计分规则一致

#### Scenario: 一人命中时另一人未射击
- **WHEN** 一名玩家命中并补靶，另一名玩家保持不动
- **THEN** 只有击中的玩家更新自己的靶位和命中数

#### Scenario: 使用桌面图标和本地偏好
- **WHEN** 玩家使用自己的桌面图标或修改瞄准及音效设置
- **THEN** 相关素材与设置留在本机，房间内仅共享对局所需的身份、状态、计时、靶位生成参数和成绩
- **AND** 不传输桌面图像、图标、文件信息或鼠标轨迹

### Requirement: 统一排名与下一轮

房主 MUST 汇总本轮完赛成绩，并向仍在房间的玩家提供同一份计分板。计分板 MUST 显示昵称、名次、命中数、射击次数与命中率，按命中数降序，同分并列，后续名次按排在前面的人数确定。未完赛玩家 MUST 显示状态且不参与排名。结算后房主 MUST 能让当前房间返回准备状态。

#### Scenario: 比较成绩与并列
- **WHEN** 三名完赛玩家分别命中 12、12 和 8 次
- **THEN** 所有仍在房间中的玩家都看到名次 1、1、3，两个命中 12 次的玩家并列第一

#### Scenario: 零射击与未完赛
- **WHEN** 一名玩家零射击打完，另一名玩家放弃或在成绩确认前掉线
- **THEN** 完赛玩家以 0 命中、0 射击、0% 命中率参与排名，未完赛玩家标明原因且无名次
- **AND** 若全员未完赛，计分板不显示获胜者

#### Scenario: 等待其他成绩
- **WHEN** 玩家本地对局结束，房主仍在等待本轮成绩
- **THEN** 玩家看到等待结算状态且光标可用，房主最迟在统一截止后的 5 秒收分窗口关闭时确定排名
- **AND** 缺失成绩的玩家记为未完赛，重复提交、窗口关闭后的提交及上一轮的成绩不改变排名

#### Scenario: 原房间再赛
- **WHEN** 房主从计分板返回房间
- **THEN** 仍连接的玩家留在房间，准备状态重置，新一轮使用新的对局标识与靶位种子，上一轮的成绩不带入

### Requirement: 竞赛中断与房间关闭

竞赛 MUST 使用连续计时。玩家在截止前按 `Esc`、失焦、失去鼠标控制、遇到使工作区坐标失效的显示变化或离开房间时，MUST 结束其本轮参与并释放输入和叠层反馈。房主仍在房间时其他人照常完成。房间连接中断 MUST 被检测并展示原因，房主关闭房间或失联时未结算的比赛 MUST 取消。

#### Scenario: 比赛中切出窗口或主动放弃
- **WHEN** 一名参赛者在截止前切出窗口或按 `Esc`
- **THEN** 该玩家立即释放光标并撤回桌面遮盖及命中反馈，显示本轮已退出的原因
- **AND** 回焦后不接管光标，该玩家仍可留在房间查看结算，其余参赛者继续计时

#### Scenario: 参赛者掉线
- **WHEN** 普通玩家在比赛中断开连接或网络静默
- **THEN** 断开的玩家在检测到连接中断后释放输入并看到连接中断提示，房主在成绩未确认时将其记为未完赛
- **AND** 该玩家可以在房间重新开放后加入下一轮

#### Scenario: 房主关闭程序或失联
- **WHEN** 房主进程退出或其他玩家检测到房主连接中断，且本轮尚未收到正式结算
- **THEN** 其他玩家释放输入和桌面叠层反馈，看到比赛取消提示，并可返回单机或局域网入口
