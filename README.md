# 桌面甩枪 · Desktop Icon Flick

在自己的 Windows 桌面上练快速切靶。壁纸和任务栏保持原位，准星固定在视口中央；鼠标转动游戏视角，左键击发。默认直接用桌面图标的图像做靶子，保留图标本身的形状和透明区域。也可以取消勾选改用普通小球。

## 运行

在 Windows 10/11 x64 的 PowerShell 7（`pwsh`）中，从项目根目录运行：

```powershell
.\build.ps1
```

双击 `bin\DesktopIconFlick.exe`。需要 .NET Framework 4.8（Windows 11 和新版 Windows 10 已内置），构建不需要 .NET SDK 或外部包。移动程序时请保留相邻的 `DesktopIconFlick.exe.config`。训练层透过的是窗口后方的真实画面：若看到其他应用而不是壁纸，先最小化挡住桌面的窗口。

1. 先露出主屏桌面，再打开程序。图标读取完成后，点击「开始训练」。
2. 用「局内 DPI」直接调训练灵敏度，数值越大转向越快。默认局内 DPI 为 800，水平 FOV 为 100°。需要按物理距离校准时，展开「高级校准」，填鼠标当前硬件 DPI 和水平转一圈所需的厘米数，再点「应用校准」。应用会把结果填入「局内 DPI」。
3. 30 秒内，三枚靶子集中在开局朝向附近。打掉一枚后立即在同一区域补一枚。能定位的图标和文字也会从桌面原位暂时消失，直到本局暂停或结束。点击「继续训练」可恢复本局，暂停时再次按 `Esc` 可退出。

可定位的图标原位会露出对齐的壁纸。Wallpaper Engine 使用独立壁纸窗口时，露出的背景会继续播放。壁纸无法可靠显示时，原位图标仍可见。

程序不截取桌面，也不修改或打开真实图标。单机训练离线运行。设置与单机个人最佳保存在 `%LOCALAPPDATA%\DesktopIconFlick\profile.txt`。

## 局域网竞赛

1. 让 2 至 8 名玩家的电脑连到同一局域网子网，使用同一版本。先在训练页选好各自的 DPI、FOV、靶外观和音效，再点「局域网竞赛」。
2. 房主填写昵称、选与朋友相通的网卡、点击「创建房间」，把房间里显示的 IPv4 地址和端口告诉朋友。默认端口为 `47618`。朋友填写自己的昵称以及房主的地址和端口，点击「加入房间」。
3. 各自点击「准备」并让游戏窗口保持前台。全员准备后，房主点击「开始竞赛」。3 秒倒计时结束后，每人独立打 30 秒。初始靶位相同，各自保留自己的图标或小球外观，补靶会随命中顺序变化。
4. 结束后大家看到同一份排名，命中数多的靠前，同分并列。按 `Esc` 或切出窗口会结束本人本轮参与。房主选「返回房间」后可以再次准备开赛。竞赛成绩只用于本轮排名。

如果连接失败，核对双方是否处于同一子网并确认填写的是房主所选网卡的地址和显示的端口。还可检查房主的防火墙是否允许程序接收相应局域网连接，以及路由器是否启用了访客网络隔离。局域网只交换组局、计时和成绩消息，桌面图标、画面和鼠标轨迹留在本机。

## 验证

```powershell
.\build.ps1 -Test
.\tests\desktop-smoke.ps1
$env:OPENSPEC_TELEMETRY='0'
openspec validate --specs --strict
```

自动测试覆盖灵敏度、连续补位、暂停时钟、图标来源和壁纸遮盖。冒烟脚本在交互式 Windows 会话中检查物理窗口边界、空白叠层是否接收鼠标命中，以及启动时光标是否自由。实机试玩步骤见 [桌面验收清单](docs/desktop-acceptance.md)。
